# Use Cases

Every industry has the same meeting. Someone shows a chatbot that answers anything, the room nods, and six weeks later the chatbot has promised a refund policy the company doesn't have, to a customer who screenshotted it.

The problem was never that the model wasn't smart enough. The problem is that nobody decided where the model stops and the business rules start.

That's what I'm for. The pages in this section are small, real systems — each one built in less than an hour, most in far less, with a local model on an ordinary laptop. They aren't toys, and they aren't production either. They're the skeleton: the part where you decide what the model is allowed to decide, and everything else is plain code you can read, test and trust.

Every page follows the same shape. A short story about what goes wrong without a skeleton. Then the build: the commands, every file in full, how to run it, how to talk to it, and what actually happened when you did. Then the honest part — where the proof of concept ends and what it would take to put it in front of real people.

Copy the code. Run it. Break it on purpose. Then make it yours.
